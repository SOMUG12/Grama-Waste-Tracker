# Grama-Waste-Tracker

Smart waste management Android application for villages and towns.

## Features
- Live garbage truck tracking
- Resident dashboard
- Driver dashboard
- Panchayat admin panel
- Blackspot garbage reporting
- Firebase Authentication
- Firebase Realtime Database
- Google Maps integration
- Kannada language support
- Notification alerts

## Technologies Used
- Java
- Android Studio
- Firebase
- Google Maps API
- XML

## Modules
### Resident
- Track garbage vehicle
- Report garbage blackspots
- Waste segregation guide
- Receive notifications

### Driver
- Start/stop tracking
- View assigned blackspots
- Update collection status

### Admin
- View blackspot reports
- Monitor drivers
- Manage reports

## Future Improvements
- Real-time route optimization
- AI-based waste classification
- Push notifications
- Cloud image storage
